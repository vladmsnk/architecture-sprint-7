### Описание текущего решения:

2 вида пользователей:
- клиенты — потенциальные покупатели
- собственники — уже приобрели жилье

Функциональность для клиентов:
- онлайн-витрина для побора и бронирования жилья
- онлайн-тур позволяет просматривать жилье в режиме онлайн
- онлайн-сделка проводит сделки по покупке недвижимости онлайн

Функциональность для собственников:
- оплата жкх
- получение инфы от упр. компании
- просмотр актуальных данных о запланированных работах и история проведенных работ
- управление умным домом

**Сервисы для управления продажами:**
- витрина продаж — агрегация данных
- client-tour-app — онлайн тур
- client-mart-app — онлайн сделка
- client-crm-app — управление клиентскими данными
- client-mart-estate-app — управление данными о недвижимости

**Сервисы ЖКУ**
- витрина сервисов для собственников
- tenant-core-app - сервис предоставления услуг
- crm - сервис управления данными собственников

**Сервисы по управлению финансами**
- accountant-service-1 — система фин. учета
- AD

**Аналитика**
- хранилище данных greenplum — единое хранилище данных для всех систем
- S3

2) **Риски по каждой категории данных**

Публичные данные:
- Данные по объектам недвижимости
- Данные для организации онлайн-тура
  Риски:
- искажение данных (Значительный)
- некачественные данные (Незначительный)
  Пояснение:
- Предоставление неточных и искаженных данных может привести к финансовым потерям компании, а также к потерям клиентов. Например, предоставление заниженной стоимости недвижимости и послежующая продажа по данной стоимости приведет к репутационым потерям.

Внутренние данные:
- Данные для отображения карточки клиента
- Данные для отображения профиля клиента
- Список услуг ЖКУ
  Риски:
- утечка данных (Значительный)
- потеря данных (Критический )
  Пояснение:
- Потеря или утечка данных может использоваться для наполнения  данным фишинговых сайтов. Также утечка таких данных приведет к репутационным потерям

Конфиденциальные данные:
- Расширенные данные по объектам недвижимости
- Расширенная информация по клиентам
- Информация по сделкам
- Данные собственников
- Данные по финансовым операциям
  Риски:
- утечка данных (Значительный)
- потеря данных (Критический)
- искажение данных (Критический)
  Пояснение:
- потеря и утечка таких данных может привести к огромным финансовым потерям

Секретные данные:
- Пароли для получения доступа к Базам Данных
- Пароли для получения авторизационного доступа с расширенными полномочиями в системе
  Риски:
- утечка данных (Критический)
- потеря данных (Критический)
- искажение данных (Критический)
  Пояснение:
- потеря таких данных может являться критической для компании и остановить всю работу
