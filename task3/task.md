### Интеграция умного дома в контекст сервисов по работе с собственниками

#### Необходимые доработки 
1) Реализация функционала Identity and Access Management system (IAM) для разграничения прав доступа. 
Можно использовать способ авторизации на основе ABAC, где в качестве атрибутов будут служить: (username, timestamp, user_role). 
2) Атрибуты будут распознаваться с помощью внешнего ML сервиса.
3) Реализовать сервис tenant-smart-home-service, который будет общаться с внешними системами умного дома, например, устройства дверных замков и устройства шлагбаунов
4) tenant-smart-home-service будет обращаться в IAM для авторизации доступа, в котором будет реализована ABAC политика 

Требования к безопасности:
1) Авторизация доступа будет реализована в сервисе IAM на основе ABAC. 
IAM будет гарантировать, что доступ можно получить только в том случае, если IAM подтвердил, что доступ существует. 
2) Пользователь может получить доступ только в том случае, если он предоставил свою биометрию или номерной знак. 
Эмбединги биометрии хранятся на стороне внешнего ML сервиса, который удовлетворяет требованиям 152 ФЗ. 
3) Все каналы передачи данных, включая взаимодействие с внешним ML-сервисом, API устройств умного дома, должны быть зашифрованы на основе протокола TLS.
